常见问题

我的私钥会被平台看到吗？

取决于你选哪一种模式。「平台托管」由平台产生并加密存放，缺省不能下载，要管理员针对该账号明确打开，之后每次下载都会写进审计纪录；「自备 CSR」的私钥完全不经过平台；「Agent 模式」的密钥由你机房里的 Agent 产生、留在你自己的机器上，永远不会上传。

支持哪些 DNS 服务商的自动验证？

目前集成 10 家：GoDaddy、NS1、Namecheap、Cloudflare、AWS Route 53、腾讯云 DNSPod、Google Cloud DNS、UltraDNS、Constellix、Akamai Edge DNS。清单持续扩充，若你使用的服务商尚未支持，可改用手动验证，或与我们联系评估集成。

证书可以自动推送到哪些 CDN？

目前支持 7 家：Apeiro8 CDN、腾云 CDNRay、CDNetworks、阿里云、腾讯云 CDN／EdgeOne、EdgeNext、CDN5。推送完成后，平台会从节点巡检实际连接确认证书链与生效状态，而不是只回报 API 调用成功。

内网里不对外的服务器也能自动部署吗？

可以，使用内网代理程序（Agent）：一台 Linux 机器运行 Agent 作为 hub，经 SSH 把证书安装到你列出的设备。Linux 主机（nginx、haproxy、Apache）与 Windows Server 2022 的 IIS 都已实测可用；更旧的 Windows 版本尚未验证，建议先在可测试的机器上确认。私钥在 hub 上产生，只在你的内网传递，平台看不到。Agent 的安装包附有签章，可用 ssh-keygen -Y verify 验证来源。此功能需要 Enterprise 方案。

这张证书是谁签发的？主流浏览器都会信任吗？

证书由 GoGetSSL 的 DV CA 签发，信任链往上经 USERTrust 连到 Sectigo 的公开信任根证书——该根证书已内置于所有主流浏览器与操作系统的信任库，不需用户额外安装任何东西。

收费方式是什么？有月费吗？

证书依张计价，单一域名 US$30 起／年、通配符 US$90 起／年，效期内重签不加价，从账户余额扣款。自动化功能则依订阅方案：Basic 免费但不含自动化；Pro US$29／月提供 CDN 自动部署、DNS 自动验证与节点巡检，团队上限 5 人；Enterprise US$149／月再加上内网代理程序与不限成员。新账号注册即享 14 天 Pro 试用，到期自动转为 Basic，不会自动扣款。
