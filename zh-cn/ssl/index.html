什么是 SSL 证书自动化平台？

SSL 证书是网站启用 HTTPS 加密连接的必要元件，但传统的证书申请、验证与更新流程往往需要人工介入：手动创建 DNS 验证记录、下载证书文件、逐一上传至服务器或 CDN，且证书通常每隔数月就需要重新签发，稍有疏忽就可能因证书过期而导致网站出现安全性警告。

Kineticlinks SSL 证书自动化平台将整个流程串接为单一界面：平台整合 GoDaddy 等主流 DNS 服务商的 API，可自动完成域名所有权验证，免去手动新增 TXT 或 CNAME 记录的步骤。证书签发完成后，也能自动推送至多个品牌的 CDN 节点，让证书部署与 CDN 加速服务无缝衔接。

平台同时提供证书到期提醒与自动续签机制，降低因人为疏忽导致证书过期的风险，特别适合同时管理多个域名、或需要频繁在不同 CDN 服务商之间切换证书的团队。

常见问题

使用这个平台需要先具备域名的哪些权限？

需要有域名的 DNS 管理权限，平台会通过整合的 DNS 服务商 API 自动创建验证记录；若您的 DNS 服务商尚未支持自动整合，也可改用手动验证方式。

证书到期前平台会主动通知吗？

会。平台会在证书到期前主动提醒，并可依设置启用自动续签，降低因忘记更新而导致网站出现不安全警告的风险。

签发的证书可以用在 Kineticlinks 以外的 CDN 或主机吗？

可以。平台签发的是标准 SSL 证书，可下载后应用于任何支持 SSL 的服务器或 CDN 服务，并非仅限定 Kineticlinks 自家服务使用。

平台支持哪些 DNS 服务商的自动验证？

目前已整合 GoDaddy 等主流 DNS 服务商，并持续扩充支持清单，若您使用的服务商尚未支持，欢迎与我们联系评估整合可行性。

这个平台是免费使用吗？收费方式为何？

平台功能本身不另外收费，费用即证书本身：单一域名证书 US$30／年，通配符证书 US$90／年，有效期内自动重签不加价。没有月费或账户费。首张证书若不符合需求可全额退费。
