什麼是 SSL 憑證自動化平台？

SSL 憑證是網站啟用 HTTPS 加密連線的必要元件，但傳統的憑證申請、驗證與更新流程往往需要人工介入：手動建立 DNS 驗證紀錄、下載憑證檔案、逐一上傳至伺服器或 CDN，且憑證通常每隔數月就需要重新簽發，稍有疏忽就可能因憑證到期而導致網站出現安全性警告。

Kineticlinks SSL 憑證自動化平台將整個流程串接為單一介面：平台整合 GoDaddy 等主流 DNS 服務商的 API，可自動完成網域所有權驗證，免去手動新增 TXT 或 CNAME 紀錄的步驟。憑證簽發完成後，也能自動推播至多個品牌的 CDN 節點，讓憑證部署與 CDN 加速服務無縫銜接。

平台同時提供憑證到期提醒與自動續簽機制，降低因人為疏忽導致憑證過期的風險，特別適合同時管理多個網域、或需要頻繁在不同 CDN 服務商之間切換憑證的團隊。

常見問題

使用這個平台需要先具備網域的哪些權限？

需要有網域的 DNS 管理權限，平台會透過整合的 DNS 服務商 API 自動建立驗證紀錄；若您的 DNS 服務商尚未支援自動整合，也可改用手動驗證方式。

憑證到期前平台會主動通知嗎？

會。平台會在憑證到期前主動提醒，並可依設定啟用自動續簽，降低因忘記更新而導致網站出現不安全警告的風險。

簽發的憑證可以用在 Kineticlinks 以外的 CDN 或主機嗎？

可以。平台簽發的是標準 SSL 憑證，可下載後應用於任何支援 SSL 的伺服器或 CDN 服務，並非僅限定 Kineticlinks 自家服務使用。

平台支援哪些 DNS 服務商的自動驗證？

目前已整合 GoDaddy 等主流 DNS 服務商，並持續擴充支援清單，若您使用的服務商尚未支援，歡迎與我們聯繫評估整合可行性。

這個平台是免費使用嗎？

平台的方案與計費依實際使用的憑證數量與功能需求而定，歡迎聯繫我們的團隊取得符合您需求的方案說明。
