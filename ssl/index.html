安全性與治理

這些是平台目前實際做到的，完整說明（含還沒做到的部分）公開在平台的安全性頁面

兩步驟驗證與登入保護

支援驗證器 App 與備援碼，擁有者可要求全團隊啟用；可設定閒置自動登出與允許登入的來源網路。

五種角色，逐項權限

擁有者、admin、operator、billing、viewer；每一條 API 路由都必須宣告所需權限，否則自動測試會讓建置失敗。

API 金鑰有範圍限制

只能做勾選的事，不超過建立者的權限；可設到期日與來源 IP 範圍，建立者離開團隊時自動失效。

訂單核准與稽核紀錄

可要求 operator 與 API 金鑰的訂單先經核准；登入、權限變更、私鑰下載等都會記錄，可匯出 CSV 或用 API 拉取。

常見問題

我的私鑰會被平台看到嗎？

取決於你選哪一種模式。「平台代管」由平台產生並加密存放，預設不能下載，要管理員針對該帳號明確開啟，之後每次下載都會寫進稽核紀錄；「自備 CSR」的私鑰完全不經過平台；「Agent 模式」的金鑰由你機房裡的 Agent 產生、留在你自己的機器上，永遠不會上傳。

支援哪些 DNS 服務商的自動驗證？

目前整合 10 家：GoDaddy、NS1、Namecheap、Cloudflare、AWS Route 53、騰訊雲 DNSPod、Google Cloud DNS、UltraDNS、Constellix、Akamai Edge DNS。清單持續擴充，若你使用的服務商尚未支援，可改用手動驗證，或與我們聯繫評估整合。

憑證可以自動推播到哪些 CDN？

目前支援 7 家：Apeiro8 CDN、騰雲 CDNRay、CDNetworks、阿里雲、騰訊雲 CDN／EdgeOne、EdgeNext、CDN5。推播完成後，平台會從節點巡檢實際連線確認憑證鏈與生效狀態，而不是只回報 API 呼叫成功。

內網裡不對外的伺服器也能自動部署嗎？

可以，使用內網代理程式（Agent）：一台 Linux 機器執行 Agent 作為 hub，經 SSH 把憑證安裝到你列出的設備。Linux 主機（nginx、haproxy、Apache）與 Windows Server 2022 的 IIS 都已實測可用；更舊的 Windows 版本尚未驗證，建議先在可測試的機器上確認。私鑰在 hub 上產生，只在你的內網傳遞，平台看不到。Agent 的安裝包附有簽章，可用 ssh-keygen -Y verify 驗證來源。此功能需要 Enterprise 方案。

這張憑證是誰簽發的？主流瀏覽器都會信任嗎？

憑證由 GoGetSSL 的 DV CA 簽發，信任鏈往上經 USERTrust 連到 Sectigo 的公開信任根憑證——該根憑證已內建於所有主流瀏覽器與作業系統的信任庫，不需使用者額外安裝任何東西。

收費方式是什麼？有月費嗎？

憑證依張計價，單一網域 US$30 起／年、萬用字元 US$90 起／年，效期內重簽不加價，從帳戶餘額扣款。自動化功能則依訂閱方案：Basic 免費但不含自動化；Pro US$29／月提供 CDN 自動部署、DNS 自動驗證與節點巡檢，團隊上限 5 人；Enterprise US$149／月再加上內網代理程式與不限成員。新帳號註冊即享 14 天 Pro 試用，到期自動轉為 Basic，不會自動扣款。
