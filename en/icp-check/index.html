Why check ICP filing status in real time?

Under mainland Chinese regulation, any domain served from mainland infrastructure or accelerated through mainland CDN nodes must hold a valid ICP filing number issued by the MIIT. If the filing details no longer match reality, a change of registrant was never updated, or a compliance review cancels the record, the hosting provider blocks the domain and the site stops resolving.

The Kineticlinks ICP lookup queries a live data source, so entering a domain returns the current MIIT filing status, registrant name, registrant type (company or individual), ICP filing number and approval date — without working through the official system's captcha flow by hand.

Whether you are running routine checks, doing background work on a domain before buying it, or assessing cross-border compliance, the tool gives you a verifiable filing result immediately.

Frequently asked questions

When does a website need an ICP filing?

Whenever your site is served from a server located in mainland China, or you enable mainland Chinese CDN acceleration nodes, a filing is required. If everything is deployed in Hong Kong or elsewhere overseas and no mainland node is involved, a filing is not mandatory.

What does a "not filed" result mean?

It means the MIIT system currently holds no valid filing record for that domain. Until that changes, the domain cannot point at mainland servers or use mainland CDN nodes without the provider blocking access.

Will I be notified if a filing is cancelled?

Cancellations happen during periodic reviews or when details no longer match — a lapsed registrant, a shell filing, contact details that no longer work. The notice does not always arrive in time, which is why checking proactively is worth doing.

Is the data returned live?

Yes. The tool requests and parses the current filing status at query time, so you see the latest MIIT record rather than a cached copy.

If I host overseas but want faster access from China, do I still need a filing?

Not if traffic never touches a mainland node — Hong Kong or Asia-Pacific optimised routes (CN2 GIA, 9929) and overseas CDNs are fine. To use mainland edge nodes for acceleration, an ICP filing is required.
